# Lepa Svaki Dan (Beauty & Wellbeing Concept, Beograd)

**EN, short:** static website for a beauty and wellbeing centre with two locations in Belgrade. The client (Tamara) chose design **A**; the final site lives in `v2/a-lumine` (28 pre-rendered pages: home, blog, 21 articles, 4 segment pages, special offers). Plain HTML/CSS/JS, no framework, pages are generated by node scripts. Live: https://lepa-svaki-dan-predlozi.vercel.app

## Struktura

| Putanja | Šta je |
|---|---|
| `v2/a-lumine/` | **Finalni sajt** (izabrana verzija A). Statični HTML/CSS/JS. |
| `v2/_tools/a/` | Build skripte za A: `build-pages.mjs` (generiše stranice, šabloni su u skripti), `check-pages.mjs` (provere), `sync-content.mjs`, `test-search-relevance.mjs`. |
| `v2/_shared/` | Zajednički sadržaj i brend: `content/` (cenovnik, tekstovi, članci iz Word dokumenata, rečnik pretrage), `brand/` (logotipi, tokeni, fontovi), `img/` (optimizovane slike). |
| `v2/_tools/make-deploy.py` | Pravi javnu kopiju `v2/_deploy` iz `a-lumine` (čisti razvojne beleške, verzioniše skripte, piše `vercel.json`). |
| `v2/_tools/qa/` | QA alat (`puppeteer-core`; pokreni `npm i` u tom folderu). |
| `v2/_specs/feedback3/` | **Zahtevi klijenta** za finalnu verziju (PDF + strane kao PNG). Ostali `_specs` fajlovi su analiza šablona za ranije verzije. |
| `v2/b-alder`, `v2/c-luzia`, `v2/_tools/b`, `v2/_tools/c` | Odbačene verzije B i C (arhiva). Iz C su preuzeti samo predlozi pretrage. |
| `procedure/` | Word tekstovi klijenta (21 članak, 4 segmenta), izvor za blog. |
| `lepasvakidrugidan/` | Prva (odbačena) verzija sajta, samo referenca. |
| `!!!BeautyConceptBRAND BOOK.pdf` | Brendbook klijenta (izvor istine za boje, pismo, logo). |

## Pokretanje i rad

```bash
cd v2
python3 -m http.server 8741 --directory a-lumine          # lokalni pregled
node _tools/a/build-pages.mjs && node _tools/a/check-pages.mjs   # posle izmene šablona ili sadržaja
node _tools/a/test-search-relevance.mjs                    # test relevantnosti pretrage
```

Pravilo: izmene idu u šablone u `build-pages.mjs` i u statične delove (`index.html`, `css/`, `js/`), pa se stranice ponovo generišu. Sadržaj (cene, tekstovi, kontakt) je u `v2/_shared/content/` pa se prenosi skriptom `sync-content.mjs`.

## Objava (Vercel)

```bash
python3 v2/_tools/make-deploy.py
cd v2/_deploy && npx vercel@latest deploy --prod --yes     # posle obrisati .env.local
```

Projekat na Vercelu je `lepa-svaki-dan-predlozi` (nalog vlasnika). Potreban je pristup tom projektu ili poseban Vercel nalog/link (`vercel link`). Sajt je trenutno **noindex** (preview); skinuti pre pravog lansiranja (`<meta name="robots">` u svim stranicama + `X-Robots-Tag` u `make-deploy.py`).

## Pravila projekta (važna)

- **Brendbook je zakon:** Galano Grotesque (imamo Regular i Bold, nema Light), logo samo iz `_shared/brand`, zlato kao folija (tanke linije), 75% crna `#5A5758`. Paleta finalne verzije: bež/slonovača (`#F4F2E9`) + zlato, **lila (Beauty Concept) i zelena (Wellbeing) samo kao detalji**, bez tamnih popuna i jakih kontrasta.
- **Jedan cenovnik, bez ikakve informacije o lokaciji po usluzi** (klijent seli aparate). Cene: **prvo dinari (veliko), pa evri (malo)**.
- **Osnivačica je Tamara Ćosić.** Tamara Vujačić je lekar i zadržava „dr“ (npr. „Specijalistički pregled dr Tamara Vujačić“).
- Bez em crtica (—) u fajlovima i vidljivom tekstu, numeracija 1, 2, 3 (ne 01), bez emoji, bez vidljivih hashtagova (oznake služe samo za pretragu).
- Tekst klijenta se ne menja (samo raspored). Ništa se ne izmišlja (cene, tvrdnje, adrese).
- Mobilni telefon je primarni: 320 do 1440 px bez horizontalnog skrola, dugmad 44 px, `prefers-reduced-motion`.
- U svemu što klijent vidi (stranice, dokumenti, izvorni kod objave) ne pominju se imena originalnih šablona; `make-deploy.py` čisti razvojne beleške.
- Svaki dokument/stranica potpisan: „Pripremio ECHOSYSTEM-MOTHER AGENCY“.
